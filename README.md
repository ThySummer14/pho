# 点亮回声 · ECHO RUN

单键网页节奏游戏，现含四首原创曲目。原始《一路接亮》为 120 BPM、64 秒 / 32 小节 / 117 节点；新增三首完整 REAPER 原版音乐及独立谱面。每次演奏有四拍倒数和 1.2 秒曲尾过渡。霓虹街区沿四个音乐段落变化，支持键盘与触屏。无第三方运行依赖。

## 运行

需要 Node.js 18+ 和 Python 3。

```sh
npm test
npm start
# http://localhost:4173
```

项目直接提供 `dist/` 静态文件，没有额外的 build 或 lint 配置。

## 操作

空心节点与打击环中心光点重合时，按 SPACE、F、J，或点击下方打击区。跟随清亮主音，底鼓并非每声都需要按。按住不连打，触屏仅接受主触点。Esc 暂停，R 重练本次范围（保留练习速度）。首页 Enter 开始；聚焦按钮时保留其原生键盘操作。

首次可以用 16 秒暖身。分段练习可直接选任意乐段，曲终还会推荐漏拍最多的段落。漏拍不会中止音乐。暂停 / 失焦 / 音频中断会停掉全部排程声源，继续时从本小节开头倒数四拍并回滚这一小节；本次标为练习恢复。

## 判定与记录

每次开始前选择难度，保存到本浏览器：

| 难度 | 精准 | 命中 | 接住 | 空拍与防误触 |
| --- | --- | --- | --- | --- |
| 轻松 | ±80 ms | ±130 ms | ±180 ms | 空拍不打断连击；命中后 65 ms 内的无目标重复输入不再结算 |
| 标准（默认） | ±55 ms | ±110 ms | ±150 ms | 空拍打断连击；命中后 60 ms 内的无目标重复输入不再结算 |
| 挑战 | ±40 ms | ±90 ms | 无额外档位 | 空拍打断连击；保留严格双击结算 |

以上都是半窗口宽度，边界包含。宽窗口重叠时选最近未结算节点，等距时优先较早节点。一次输入最多消费一个节点。误触保护只忽略未匹配到节点的短时重复输入，不会吞掉有效的补敲或相邻节点。“接住”保持连击，但只得 400 分；命中 700，精准 1000。漏拍 0 分。加权精准率为 `(精准 + 命中 × .7 + 接住 × .4) / 全部节点`，与单纯接亮率不同。

S+ ≥98%、S ≥90%、A ≥80%、B ≥65%、C ≥45%，其余有命中为 D；无输入不授予评级。全连要求接亮全部节点且零空击，允许普通命中和接住。5 个本地成就覆盖初次完奏、16 连击、64 连击、90% 精准率和 Full Combo。16 连击可在练习获得，其余要求完整且未使用暂停恢复的整曲。

最佳成绩按难度隔离；分段和练习恢复不能覆盖整曲最佳。分数、最佳精准率、最长连击和已获成就只存本地 `echo-records`。设置存于 `echo-feel`，判定偏移存于 `echo-offset`。

## 手感与校准

每次实际按下即时播放短触点声，独立于判定结果；可选清脆 / 温暖音色并试听。精准和每 16 连击追加轻量短泛音，打击声不再复制背景主旋律。漏拍不额外发声，空击只有按下自身的触点。短时形变、局部双环、放射线和粒子提供视觉反馈，判定位置不因特效移动。

音乐排程、轨道查询和输入都使用 AudioContext 时间轴。使用输出时间戳时将 performance 事件时间映射到声音输出时间，不额外叠加 outputLatency；回退为 currentTime 与事件时间差。显示漏拍留 75 ms 派发余量，实际按键仍按事件时间戳和所选窗口计分。

校准先听 4 拍再跟 16 拍，至少 10 次有效输入，以中位数与绝对偏差中位数判断稳定性。输入判定为 `inputSongTime − offset − noteTime`，正偏移修正晚按。画面微调独立于判定：正值让视觉光点晚到，不改变声音或成绩，避免把人的反应偏移误当显示延迟。

音乐 / 音效独立调音量；减少动态效果默认尊重系统偏好，保留必要轨道运动并固定背景几何、省略碎粒与放射线。设备延迟与主观听感仍需实际设备校准和试玩。

## 项目结构与依据

- `dist/index.html`、`style.css`：选曲、难度、HUD、暂停、结果和设置。
- `dist/app.js`：生命周期、时钟、统一输入与轨道呈现。
- `dist/engine.js`：纯判定、档位、轨道插值、校准。
- `dist/music.js`：合成音乐、短触点、混音和声源清理。
- `dist/scene.js`：四章城市、乐句配色、受限命中特效。
- `dist/progress.js`：评级、按难度记录、成就规则。
- `dist/chart.json`：原创 117 节点谱面，本轮未增删。
- `tests/`：判定、音效、场景、记录与模拟生命周期。

[调研依据](research/rhythm-design.md)比较了 ADOFAI、osu!、Rhythm Doctor、Muse Dash、Beat Saber 的官方设计资料，并区分源事实与本项目取舍。实际验证记录见 [QA.md](QA.md)。

没有分析服务、第三方请求、外部字体、账户或付费 API。音乐为原创合成或原创 REAPER 导出，画面由本地代码绘制。

## 新增：变速练习

分段练习可选 75% / 85% / 100% / 115%（90 / 102 / 120 / 138 BPM）。重新排程合成音符，不改变音高；倒数、轨道、音乐、输入共享速度。判定窗口、输入偏移和误差反馈始终使用真实毫秒，不因慢速自动放宽。四拍倒数跟随练习速度。暂停回滚、R 重开与结算重试保留当前范围和速度；返回首页开始整曲恢复 100%。练习不能覆盖整曲最佳。

## 新增：乐句回放与集中练习

结算按四小节显示精准率、漏拍、空拍，点任意格可只重练这四小节；描边标记按失分比例与空拍推荐的句子，不再总是推荐整个 16 秒段落。误差标准差与平均早晚分别描述稳定性和偏向，至少 8 次命中才显示稳定性数值；不会根据一次演奏自动改校准。结果区支持独立滚动，窄屏格子为两列。

## 新增：四首歌，四种节奏与景观

- 一路接亮：120 BPM / 117 节点，霓虹街区，保持原谱不变。
- 庭院明信片：112 BPM / 141 节点，Bossa Nova，拱廊庭院；拨弦开场进入长笛切分。
- 玻璃公路：112 BPM / 126 节点，Synthwave，地平线与透视公路；琶音进入主旋律与留白。
- 银色湍流：172 BPM / 101 节点，Drum & Bass，流体光带；稀疏主音、钟声应答与澄空段保留呼吸。

首页顶部选曲。新曲原速使用完整 REAPER MP3 音乐，按 AudioContext 时钟播放与从分段位置重新起奏；不会在播放原版时叠加合成伴奏。75/85/115% 为明确标注的练习合成版，按同一份最终乐谱重新排程，保留音高但不是原版音色。场景以音乐段落调节强度，减少动态效果时固定装饰几何和脉动。

新曲成绩按曲目和判定档位隔离，原有 `echo-records` 保持原格式；新曲使用各自的 `echo-records-<song>` 键。音频来源与验证见 [音乐说明](dist/audio/README.md)。

本轮自动化结果见 QA.md；修改后真实浏览器试玩和实体设备听感尚未验证，环境阻塞详情已明确记录。

## 手机界面

首页使用可滚动的紧凑选曲布局；游戏区域贴合当前可见视口，支持短竖屏、横屏及设备安全区。打击区保留“按下立即判定”，松手、拖出与取消不会额外触发；双指不会重复计分。设置与结果可独立滚动。最新实测范围及限制见 QA.md。

## 曲目美术：纸墨庭院

《庭院明信片》现在采用独立的纸墨庭院主题：暖纸色、淡墨山影、拱廊与枝叶、深色轨道、局部墨晕命中反馈。选曲、游戏、暂停、结果与设置使用同一套清晰的深色文字。这个方向是对拨弦、长笛与乐句留白的视觉诠释，并不把 Bossa Nova 当作中国音乐。其他曲目保留各自原有的霓虹、公路或流体风格。

画面完全由原创轻量 Canvas/CSS 绘制，不新增图片下载。减少动态效果时枝叶与墨晕几何固定；判定位置、谱面、计分及触控时机不变。
